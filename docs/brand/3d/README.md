# 3D objects

The glossy clay objects in the app (`3d/*.webp`) are original renders generated for this project with an image-generation tool, in the style of the user's reference images. They are not stock, not taken from the reference images and not third-party assets.

How they were processed: background removed with rembg (isnet-general-use), trimmed, resized to 512 × 512 and saved as WebP (14–23 KB each).

They are decorative only: every use has `alt=""` and `aria-hidden="true"`.
